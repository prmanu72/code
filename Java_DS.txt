  12. Common CS Data Structures Represented in Java

  These may not always have a dedicated class name, but Java supports them via classes above:

  - Dynamic array → ArrayList
  - Linked list → LinkedList
  - Stack → Stack, Deque, ArrayDeque
  - Queue → Queue, LinkedList, ArrayDeque
  - Deque → ArrayDeque, LinkedList, ConcurrentLinkedDeque
  - Hash table → HashMap, Hashtable, ConcurrentHashMap
  - Tree / balanced BST → TreeMap, TreeSet
  - Heap → PriorityQueue, PriorityBlockingQueue
  - Skip list → ConcurrentSkipListMap, ConcurrentSkipListSet
  - Bit vector → BitSet
